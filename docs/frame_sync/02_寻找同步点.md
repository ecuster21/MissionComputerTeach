# 寻找同步点

这张图对应当前 `try_find_sync()` 的实现。

```mermaid
flowchart TB
    A[进入 try_find_sync] --> B{当前有效字节数<br/>是否小于 frame_length + 2 ?}
    B -- 是 --> C[offset = 0<br/>返回 false]
    B -- 否 --> D[从 i = 0 开始扫描]

    D --> E{i + frame_length + 1 < bytes_in_buffer ?}
    E -- 否 --> F[offset = 0<br/>返回 false]
    E -- 是 --> G{buffer[i] == EB<br/>且 buffer[i + 1] == 90 ?}

    G -- 否 --> H[i = i + 1]
    H --> E

    G -- 是 --> I{buffer[i + frame_length] == EB<br/>且 buffer[i + frame_length + 1] == 90 ?}
    I -- 否 --> H

    I -- 是 --> J[offset = i]
    J --> K[返回 true]
```

## 关键点

- `frame_length` 是运行时参数，不再固定写死成 `64`
- 因此同一套同步逻辑可以同时支持 `64` 字节和 `32` 字节节点
