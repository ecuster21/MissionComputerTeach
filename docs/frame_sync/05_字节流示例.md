# 字节流示例

这张图用一个简化字节流示例说明为什么“双帧头同步”比“单帧头同步”更可靠。

```mermaid
flowchart LR
    A[无效字节<br/>11 22 33 44] --> B[候选帧头<br/>EB 90]
    B --> C[帧体<br/>类型/源ID/目的ID/数据/时间戳]
    C --> D[CRC8 1 字节]
    D --> E[下一帧帧头<br/>EB 90]
    E --> F[下一帧帧体<br/>类型/源ID/目的ID/数据/时间戳]
    F --> G[下一帧 CRC8 1 字节]
```

## 程序如何判断

程序不会只看到第一个 `EB 90` 就认定同步成功，而是继续检查：

- 当前位置是否是 `EB 90`
- `当前位置 + frame_length` 是否还是 `EB 90`

因此同一套逻辑既可以用于 `64` 字节帧，也可以用于 `32` 字节帧。
